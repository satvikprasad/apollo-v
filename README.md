# Apollo-V
A simple Music Visualiser for macOS, scriptable in Lua: www.apollo-v.com. Predecessor to [Peggiator](https://www.github.com/satvikprasad/peggiator).

![Apollo-V Preview](https://github.com/satvikprasad/apollo-v/assets/19403082/7b47f4ed-745c-451c-9901-b208186145b2)

Written in C, Objective-C (for MacOS specific features), and extensible in Lua. Rendering is performed using Raylib + OpenGL.
